# Test-Course Linking - Quick Start for Instructors

## What's New?
You can now link tests with your courses! When you link a test to a course, students enrolled in that course get **free access** to the test.

## Quick Steps

### Create a New Test with Course Link
1. Go to **Instructor > Create Test**
2. Fill in test details (title, description, duration, type)
3. Scroll to **Link to Course (Optional)**
4. Select your course from the dropdown
5. Click **Create Test**
6. ✅ Done! Enrolled students now have free access

### Edit Existing Test to Link a Course
1. Go to **Instructor > My Tests**
2. Click **Edit** on the test
3. Scroll to **Link to Course (Optional)**
4. Select a course
5. Click **Save**
6. ✅ Updated! Students can now access this test for free

### Create a Standalone Test (Purchasable)
1. Go to **Instructor > Create Test**
2. Fill in test details
3. Leave **Link to Course** as "No course selected"
4. Click **Create Test**
5. ✅ Students can now purchase this test

## Pricing Rules

| Scenario | Student Access | Cost |
|----------|-------|------|
| Test linked to course | Enrolled students | FREE ✓ |
| Test linked to course | Non-enrolled students | Must purchase |
| Standalone test | All students | Must purchase |
| Test in series | Series members | Series price applies |

5. ✅ Access granted (FREE - no payment needed)

## Tips & Best Practices

✅ **DO:**
- Link tests to courses for better organization
- Use this to make courses more valuable
- Create several tests for a course
- Link different test types (practice, quizzes, finals)

❌ **DON'T:**
- Force students to buy content that's already free
- Link a test to multiple courses (not supported - choose primary course)
- Unlink a test students are already using

## FAQ

**Q: Can I change which course a test is linked to?**
A: Yes! Edit the test and select a different course, or leave it blank to make it standalone.

**Q: Will existing students lose access if I link a test to a course?**
A: No, they'll still have access. The linking just determines pricing for new students.

**Q: Can a test be linked to multiple courses?**
A: Not currently. Link it to your primary course. Students in other courses can purchase it.

**Q: What if I sell a course but include a linked test?**
A: The test pricing is automatic:
- Enrolled students (paid or free course) → FREE test
- Non-enrolled → Must purchase separately

**Q: Can students see which tests are in their course?**
A: Yes! They'll see tests in the course materials section.

**Q: How do students purchase a standalone test?**
A: They can:
- Add test to cart individually
- Purchase as part of a test series
- These work exactly like before

## Support

**Issue:** Can't see course dropdown
- Verify you have at least one course created
- Check you're logged in as instructor

**Issue:** Students can't access test
- Check student is enrolled in course (status: Approved/Active)
- Verify test is linked to correct course
- Check test has published questions

**Issue:** Can't unlink a test from course**
- Edit the test
- Change course to "No course selected"
- Save
